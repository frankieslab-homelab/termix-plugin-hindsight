# Changelog

## 0.2.0

### Added

- Hindsight WebView in the Termix mobile app for phones and tablets

### Fixed

- Bank selector and refresh controls fit narrow mobile screens
- Metrics scroll within the mobile WebView instead of relying on page scrolling

## 0.0.1

### Added

- A Hindsight tab with service health, latency and API version
- Memory, observation, document and link counts per bank, with a bank switcher
- Consolidation and background operation queues, with failures highlighted
- Admin settings for the Hindsight URL, API key and default bank
- Live deployment verification and smoke-test instructions for multiple banks

### Fixed

- Sidebar icon sizing now honors the size passed by the Termix layout
- Deployment-neutral documentation and examples for public use
